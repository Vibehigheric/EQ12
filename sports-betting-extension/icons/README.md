# Sports Betting Extension Icons

This directory contains the extension icons in different sizes.

Since I cannot create actual PNG image files, you'll need to add these icons manually:

## Required Icons:
- `icon16.png` - 16x16 pixels (toolbar/menu icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Design Suggestions:
- Use a sports betting theme (dice, target, chart, etc.)
- Colors: Green/blue gradient to match the extension theme
- Simple, recognizable at small sizes
- Transparent background

## Quick Icon Creation:
1. Use any online icon generator (like favicon.io)
2. Create a simple 🎯 target icon with green/blue colors
3. Export in the required sizes
4. Place in this directory

## Alternative:
You can use Unicode emoji as temporary icons by creating simple colored squares with the 🎯 emoji until you get proper icons designed.
