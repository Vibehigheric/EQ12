## 🚀 **Getting Started**

### **1. Quick Installation**
```powershell
# Run as Administrator
cd C:\EQ12\eq12_godstack_final
.\Install-EQ12MasterGodstack.ps1 -Install -GitHubOrg "YourGitHubOrg"
```

### **2. Configure API Keys**
Edit `.env` file:
```env
OPENAI_SERVICE_KEY=your_openai_api_key
BING_SEARCH_API_KEY=your_bing_api_key  
GITHUB_TOKEN=your_github_token
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

### **3. Deploy GitHub Repositories**
```bash
# Create organization and repositories
gh org create EQ12-Intelligence
gh repo create eq12-godstack-core
gh repo create eq12-betting-intelligence
# ... etc for all 7 stacks
```

### **4. Test Individual Stacks**
```powershell
# Test betting intelligence
python news_aggregator.py --query-file queries_betting.txt
python enrichment.py betting  
python github_integration.py --stack betting --create-issue
```

### **5. Access Dashboard**
Visit: `http://localhost:8000`
- Browse intelligence results
- Execute manual operations  
- Monitor system health
- View cross-stack analytics
