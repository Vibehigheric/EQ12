EQ12 Governance Assistant

Privacy Policy & Data Collection Consent

Mozilla Policy Compliance: This extension complies with Mozilla Add-on Policies regarding data collection, user consent, and privacy protection.

What This Extension Does

EQ12 Governance Assistant helps you analyze web pages for governance compliance and security best practices. The extension provides:

  • Page security analysis and compliance checking
  • Governance indicators and reporting
  • Debug tools for developers (optional)
  • Privacy and security recommendations

Data Collection and Transmission

🔒 No Personal Data Collection by Default

This extension does NOT collect or transmit personal data without your explicit consent.

By default, all analysis is performed locally on your device. No browsing history, personal information, or sensitive data is sent anywhere.

🛠️ Technical Data (Optional)

When enabled, the extension may collect technical information to improve functionality:

  • Extension performance metrics
  • Error logs and debugging information
  • Browser compatibility data
  • Extension usage statistics (anonymous)

This data is:

  • Anonymous and cannot identify you personally
  • Used only to improve the extension
  • Never shared with third parties
  • Stored locally and can be deleted at any time

Your Privacy Controls

Data Collection Preferences

Choose what data you're comfortable sharing to help improve this extension:

Allow collection of anonymous performance metrics and error logs to help improve the extension. This helps us fix bugs and optimize performance.
Allow collection of anonymous usage statistics (which features are used most, etc.) to help us understand how to improve the extension.
Store additional debug information locally to help diagnose issues. This data stays on your device and is never transmitted.
Important: You can change these preferences at any time in the extension settings. Declining data collection will not affect the core functionality of the extension.

Data Security and Storage

  • Local Storage: All extension data is stored locally on your device using secure browser storage APIs
  • No External Servers: By default, no data is sent to external servers or third parties
  • Encryption: Any optional data transmission uses HTTPS encryption
  • Data Retention: You can clear all extension data at any time through browser settings

Your Rights

  • Access: View all data stored by the extension through the debug panel
  • Delete: Clear all extension data through browser settings or extension controls
  • Control: Change data collection preferences at any time
  • Transparency: Full source code is available for review
