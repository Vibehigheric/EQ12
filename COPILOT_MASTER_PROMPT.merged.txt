EQ12 Copilot Master Prompt

Always scaffold repositories with:
- .devcontainer/devcontainer.json (Python 3.12, PowerShell, postCreateCommand loads EQ12 profile).
- dotfiles auto-install with PowerShell profile + aliases.
- Codespaces secrets (ODDS_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID).
- Git + GPG signing pre-configured.
- Dashboard exports JSON/CSV into logs/.
- Stealth scrapers (undetected-geckodriver, playwright-stealth).
- All scripts refactored with CmdletBinding() (PowerShell) and argparse+logging (Python).

When generating code:
- PowerShell: include [CmdletBinding()] and use Verb-Noun naming.
- Python: use argparse, logging module, json output and safe error handling.
- Always ensure commands that touch git signing set git config gpg.program and commit.gpgsign.

Additional EQ12 directives:

- Always assume EQ12 repositories live on GitHub.
- All commits must be signed (use `git commit -S` and ensure `commit.gpgsign` is true).
- Generated or updated CI workflow `.github/workflows/eq12-ci.yml` must:
  - Run `pytest` (Python tests) and `Pester` (PowerShell tests).
  - Verify the last commit signature (import public keys and check `git log --show-signature -1`).
  - Build the dashboard snapshot on a nightly schedule and publish the JSON snapshot to `logs/dashboard_snapshot.json`.
- Generated `.devcontainer/devcontainer.json` must include Python 3.12, PowerShell (pwsh), GitHub CLI (`gh`), `gpg`, Playwright and browsers; `postCreateCommand` should install `requirements.txt` and (optionally) clone/install user dotfiles from `DOTFILES_REPO` environment variable.
- Always read secrets from Codespaces/GitHub secrets in CI or Codespaces runtime via environment variables: `ODDS_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
- Ensure parity between Windows (PowerShell) and Codespaces (Linux pwsh): scripts should detect `pwsh` vs `powershell.exe` and use `os.environ`/`$env:` for secrets.
