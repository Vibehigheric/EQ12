# Bitcoin Price Tracker

This is a simple Python script that prints the current Bitcoin price every 10 seconds using the CoinDesk API.

## Requirements

- Python 3.7+
- Requests library

## Setup

1. Install the required package:
   ```
   pip install -r requirements.txt
   ```

2. Run the script:
   ```
   python src/main.py
   ```

The script will display the current Bitcoin price in USD every 10 seconds.
