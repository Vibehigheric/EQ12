## Next Steps to Complete VPN Setup

### Step 1: Choose a VPN Provider
You need a WireGuard-compatible VPN provider. Popular options:
- **NordVPN** (supports WireGuard as "NordLynx")
- **ExpressVPN** (supports WireGuard)
- **Surfshark** (supports WireGuard)
- **Mullvad** (native WireGuard support)
- **ProtonVPN** (supports WireGuard)

### Step 2: Get Your VPN Provider's WireGuard Configuration
1. Log into your VPN provider's account
2. Look for "WireGuard" configuration download
3. Download the `.conf` file for your preferred server location
4. Note the server's public key, endpoint, and your account's private key

### Step 3: Update Your Configuration
Edit `C:\EQ12\wireguard\eq12-betting.conf` with your provider's details:

```ini
[Interface]
PrivateKey = YOUR_ACCOUNT_PRIVATE_KEY_FROM_PROVIDER
Address = YOUR_ASSIGNED_IP_FROM_PROVIDER
DNS = 1.1.1.1, 1.0.0.1

[Peer]
PublicKey = PROVIDER_SERVER_PUBLIC_KEY
Endpoint = PROVIDER_SERVER_IP:PORT
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25
```

### Step 4: Install the VPN Tunnel
Run this command to install your VPN tunnel as a Windows service:

```powershell
# Install tunnel service
powershell -ExecutionPolicy Bypass -File .\wireguard_install.ps1 -InstallTunnel

# Or use the testing script
powershell -ExecutionPolicy Bypass -File .\wireguard_test.ps1 -InstallTunnel
```

### Step 5: Test Your VPN Connection
```powershell
# Check VPN status and IP
powershell -ExecutionPolicy Bypass -File .\wireguard_test.ps1 -ShowStatus

# Test IP leak protection
powershell -ExecutionPolicy Bypass -File .\wireguard_test.ps1 -TestConnection
```

## Troubleshooting

### Common Issues

**"Tunnel Service: NOT INSTALLED"**
- Run: `powershell -ExecutionPolicy Bypass -File .\wireguard_test.ps1 -InstallTunnel`

**"No active interfaces"**
- Check your VPN provider configuration
- Ensure the tunnel service is started
- Verify your provider's server endpoint is reachable

**IP not changing**
- Verify tunnel service is running: `Get-Service WireGuardTunnel*`
- Check Windows firewall isn't blocking WireGuard
- Try different server endpoint from your VPN provider

### Manual Service Management
```powershell
# Start tunnel
Start-Service "WireGuardTunnel`$eq12-betting"

# Stop tunnel
Stop-Service "WireGuardTunnel`$eq12-betting"

# Check service status
Get-Service "WireGuardTunnel*"
```
