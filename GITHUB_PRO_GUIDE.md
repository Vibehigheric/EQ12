**What you get immediately:**

- All EQ12 tools: Black, Ruff, pytest pre-installed

### ✅ 2. Run Your First Smoke Test

```bash
python smoke_test.py
```

**Validates:**
- ✅ Environment setup (directories, dependencies)
- ✅ API connectivity patterns
- ✅ File operations (logs, data)
- ✅ Core EQ12 module imports
- ✅ Performance benchmarks

### ✅ 3. Set Up Repository Secrets

Navigate to: **Settings → Secrets and variables → Actions**

Add these secrets for automated CI/CD:

```bash
THE_ODDS_API_KEY=your_actual_key
CFBD_API_KEY=your_cfbd_key  
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
OPENAI_API_KEY=your_openai_key
STAGING_DEPLOY_KEY=your_deploy_key
```

### ✅ 4. Enable GitHub Actions

Your CI/CD pipeline is ready! Every push/PR automatically:
- 🎨 **Code formatting** (Black)
- 🔍 **Linting** (Ruff, flake8)
- 📋 **Import organization** (isort)
- 🧪 **Smoke tests** with real API validation
- 🔒 **Security scanning** (Bandit, Safety)
- 📊 **Test coverage reports**
- 📢 **Telegram notifications**

### ✅ 5. Auto-Fix Workflow

Create PR with `auto-fix` label → Automatically fixes:
- Removes unused imports/variables
- Organizes imports
- Fixes linting issues
- Formats code with Black
- Commits and pushes fixes
