## ⚙️ **Configuration Required**

### **1. GitHub Token (for Gists)**
Already configured in your `Config/config.json`:
```json
{
  "github": {
    "token": "YOUR_GITHUB_TOKEN",
    "gist": true
  }
}
```

### **2. SMTP Settings (for Email)**
```json
{
  "smtp": {
    "host": "smtp.gmail.com",
    "port": 587,
    "user": "7163618818.rj@gmail.com",
    "pass": "YOUR_GMAIL_APP_PASSWORD",
    "to": "7163618818.rj@gmail.com"
  }
}
```

**⚠️ Important:** Use Gmail **App Password**, not your regular password!
- Go to: https://support.google.com/accounts/answer/185833
- Generate 16-character App Password
- Use that in the `"pass"` field

### **3. Bitly Configuration (for Short URLs)**
```json
{
  "bitly": {
    "token": "YOUR_BITLY_GENERIC_ACCESS_TOKEN"
  }
}
```

**🔗 How to Get Bitly Token:**
1. Sign up at: https://bitly.com
2. Go to: https://app.bitly.com/settings/api/
3. Generate **Generic Access Token**
4. Copy token to config.json

**Benefits:**
- ✅ Clean short URLs (e.g., `https://bit.ly/3ExAmP1e`)
- ✅ Perfect for mobile sharing
- ✅ Easy to tap in Telegram/Discord
- ✅ Automatic fallback to full Gist URL if Bitly fails

## 🔄 **Automated Scheduling**

### **Task Scheduler Integration**
The reports can run automatically via Windows Task Scheduler:

```powershell
# Daily at 9:05 AM
schtasks /Create /TN "EQ12_Report_Daily" /TR "\"C:\EQ12\bin\Eq12Cli.exe\" report-daily" /SC DAILY /ST 09:05 /F

# Weekly on Mondays at 9:10 AM
schtasks /Create /TN "EQ12_Report_Weekly" /TR "\"C:\EQ12\bin\Eq12Cli.exe\" report-weekly" /SC WEEKLY /D MON /ST 09:10 /F

# Monthly on 1st at 9:15 AM
schtasks /Create /TN "EQ12_Report_Monthly" /TR "\"C:\EQ12\bin\Eq12Cli.exe\" report-monthly" /SC MONTHLY /D 1 /ST 09:15 /F
```

## 🔍 **Troubleshooting**

### **Common Issues**

**"Gist creation failed"**
- Check your GitHub token in `config.json`
- Ensure token has `gist` permissions
- Verify internet connectivity

**"Email send failed"**
- Test with `Eq12Cli.exe test-email`
- Check Gmail App Password (not regular password)
- Verify SMTP settings in config

**"Bitly shortening failed"**
- Test with `Eq12Cli.exe test-bitly`
- Check Bitly token in `config.json`
- Verify token has API access permissions
- System automatically falls back to full Gist URL

**"Report generation error"**
- Ensure database file exists: `Data\bankroll.db`
- Check file permissions in `Reports` folder
- Verify all NuGet packages installed (EPPlus, iText7)

### **Debug Mode**
Add to config.json:
```json
{
  "debug": true
}
```

This enables verbose error messages and stack traces.
